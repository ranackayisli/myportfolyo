# Özgül Rana Çokkayışlı · Portfolyo

Kişisel portfolyo sitem. Bilgisayar mühendisliği öğrencisiyim; web geliştirme, sağlıkta yapay zekâ, drone ve uzay araştırmaları üzerine çalışıyorum.

**Canlı site:** https://ranackayisli.github.io/myportfolyo

## İçerik

| Dosya | Açıklama |
|-------|----------|
| `index.html` | Ana site (Türkçe, brutalist tasarım) |
| `gazete/index.html` | Alternatif sürüm (İngilizce, eski gazete tasarımı) |

## Teknolojiler

Saf HTML, CSS ve JavaScript. Framework veya derleme adımı yok; dosyayı tarayıcıda açmanız yeterli.

- Fontlar: Anton, Inter, JetBrains Mono, Bodoni Moda, Source Serif 4 (Google Fonts)
- Açık ve koyu tema desteği
- Mobil uyumlu, hareket azaltma tercihine saygılı animasyonlar

## Yerelde çalıştırma

```bash
git clone https://github.com/ranackayisli/myportfolyo.git
cd myportfolyo
# index.html dosyasını tarayıcıda açın
```
